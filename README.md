# 🥐 Simple JavaFX Bakery Management

Mengimplementasikan pembelajaran pada mata kuliah Pemograman Lanjut dengan membuat Aplikasi desktop sederhana berbasis **JavaFX** untuk mencatat dan mengelola katalog produk toko roti (*bakery*). Aplikasi ini dilengkapi dengan antarmuka yang modern, fitur unggah (*upload*) gambar produk dari laptop, serta manajemen daftar menu.

## ✨ Fitur Utama
- 🥖 **Katalog Produk:** Menampilkan daftar lengkap produk toko roti beserta nama, kategori, harga, dan foto produk.
- ➕ **Tambah Produk:** Form interaktif untuk menambahkan produk baru dan memilih gambar langsung dari komputer (`FileChooser`).
- 🔍 **Detail Produk:** Tampilan detail produk yang informatif dengan format mata uang Rupiah (`Rp`).
- 🎨 **UI Modern:** Desain antarmuka yang bersih dan ramah pengguna dengan kustomisasi CSS.
